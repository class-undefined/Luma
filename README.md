# Luma

Luma 是按 `design/Luma-macOS.figcraft` 实现的 macOS 原生图片查看器。界面使用 AppKit，图片解码使用 ImageIO，图标使用 SF Symbols。项目没有第三方依赖。

## 运行

运行环境为 macOS 14 及以上。构建需要 Xcode 26 及以上，并将命令行工具切换到完整的 Xcode 安装。

在项目目录执行：

```bash
./scripts/run.sh --demo
```

脚本构建并打开 `build/Luma.app`，直接显示设计稿中的示例图库。去掉 `--demo` 后，应用首次启动显示空状态，后续启动恢复上次打开的文件夹。也可以用 `open Package.swift` 在 Xcode 中打开项目，选择 Luma scheme 运行。

生成 Release 应用：

```bash
./scripts/build.sh release
open build/Luma.app
```

生成包含 Apple Silicon 和 Intel 两种架构的应用：

```bash
./scripts/build.sh release --universal
```

构建脚本会打包图标、示例图片和文件类型声明，并使用本机临时签名。对外发行时，需要改用 Developer ID 签名并完成公证。

## 已实现的功能

- 图库：原生侧栏、网格和列表、文件名搜索、排序、收藏、最近打开和文件夹历史导航。
- 缩略图：128、192、272、384 和 512 pt 五档，默认 272 pt。菜单、五刻度滑杆、两端按钮和 Control＋滚轮共用一个状态。
- 看图：完整比例预览、缩放、适合窗口、实际大小、拖动、触控板捏合、向左旋转、胶片栏和左右键切图。
- 检查器：读取真实尺寸、文件大小、色彩描述、创建时间和 EXIF 拍摄信息，支持本地标签。
- 全屏：系统全屏窗口、玻璃操作条、收藏、共享和每隔 3 秒切图的幻灯片。macOS 26 及以上使用 `NSGlassEffectView`，较旧系统使用 `NSVisualEffectView`。
- 文件：系统打开面板、拖放图片或文件夹、Finder 的“打开方式”、系统共享面板和在 Finder 中显示文件。

Control＋滚轮仅在图库区域切换尺寸。普通滚动用于浏览。触控板累计 28 pt 有效位移后切换一档，两次切档至少间隔 160 ms；松开 Control 后的惯性事件会被消耗。切到两端时停留在当前档位。

重排时优先保持可见的选中图片及其垂直偏移。选中图片不在视口时，保持首个可见图片。滚动位置在内容边界处钳制。字体维持系统字号，图片边缘使用固定 10 pt 圆角。

## 文件与状态

打开文件夹时读取该目录下的图片，跳过隐藏文件和子文件夹。单独打开图片时，会载入所在目录，并选中这张图片。损坏或系统无法识别的图片会被跳过，状态栏显示跳过数量。

支持系统 ImageIO 可解码的图片，包括 JPEG、PNG、HEIC、WebP、GIF 和 TIFF。GIF 当前显示首帧。旋转只影响预览。收藏、标签和界面偏好保存在应用的 `UserDefaults` 中，原始文件保持原样。文件移动后，需要从新位置重新打开。

示例图库使用设计目录中的 12 张真实照片。设计稿中的文件名用于示例显示，尺寸、文件大小和拍摄信息均从图片读取。示例摄影来源保留在 `Sources/Luma/Resources/Demo/manifest.json`。

## 验证

运行核心测试：

```bash
swift test
```

运行完整验收，包括构建、签名检查和真实 AppKit 窗口交互：

```bash
./scripts/verify.sh
```

窗口验收会打开测试窗口并进入全屏，结果和截图保存在 `build/validation/`。测试使用独立的偏好域，覆盖五档尺寸、滚动位置、原生控件事件、键盘事件、搜索、收藏持久化、文件打开和全屏往返。截图需要本机允许屏幕录制。

## 代码结构

| 路径 | 用途 |
| --- | --- |
| `Sources/LumaCore/` | 尺寸档位、滚轮累积、图库几何、文件扫描和元数据读取。 |
| `Sources/Luma/` | AppKit 应用、图库、看图画布、检查器和全屏交互。 |
| `Tests/LumaCoreTests/` | 核心行为与真实图片文件测试。 |
| `Packaging/` | 应用声明和图标。 |
| `scripts/` | 构建、运行、图标生成和窗口验收入口。 |
| `design/` | 原始设计源文件、预览和素材。 |
