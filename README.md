# Luma

Luma 是按 `design/Luma-macOS.figcraft` 实现的 macOS 原生图片查看器。界面使用 AppKit，图片解码使用 ImageIO，图标使用 SF Symbols。RAW 原图使用 Core Image 解码。项目没有第三方依赖。

## 运行

运行环境为 macOS 14 及以上。构建需要 Xcode 26 及以上，并将命令行工具切换到完整的 Xcode 安装。

在项目目录执行：

```bash
./scripts/run.sh --demo
```

脚本构建并打开 `build/Luma.app`，直接显示设计稿中的示例图库。去掉 `--demo` 后，应用首次启动显示空状态，后续启动默认恢复上次打开的文件夹，可在设置中关闭。也可以用 `open Package.swift` 在 Xcode 中打开项目，选择 Luma scheme 运行。

生成 Release 应用：

```bash
./scripts/build.sh release
open build/Luma.app
```

生成包含 Apple Silicon 和 Intel 两种架构的应用：

```bash
./scripts/build.sh release --universal
```

构建脚本会打包图标、示例图片和文件类型声明，并使用本机临时签名。对外发行时，需要改用 Developer ID 签名并完成公证。

## 偏好设置与默认查看器

按 ⌘, 或选择“Luma → 设置…”打开原生偏好设置窗口。

“通用”页面可选择默认打开模式：自动、图库浏览、照片详情或纯图片查看。自动模式下，单张图片进入详情，文件夹进入图库。其余模式用于下次打开的图片、文件夹或示例图库。还可以选择是否恢复上次文件夹、是否载入相邻照片。

纯图片模式只显示完整照片和原生标题栏，支持切图、缩放、评分和右键文件操作。按 ⇧⌘P 可临时切换纯图片与详情模式。Esc 先退出全屏，再退出纯图片模式；临时切换不会改写默认打开模式。

“显示”页面可以调整缩略图大小，选择是否显示胶片栏、信息面板和看图状态栏。这些选项立即生效。纯图片模式会隐藏这些界面元素。

“默认查看器”页面显示各类图片当前关联的应用。勾选 JPEG、PNG、HEIC、RAW 等需要关联的格式，再点击“设为所选类型的默认查看器”。系统如需确认，会显示原生确认窗口。设置完成后，应用会回读实际关联结果；取消或失败的类型会显示为未更改，可刷新状态或重试。

默认应用设置需要运行打包后的 `Luma.app`，通过 `swift run` 启动的裸可执行文件不支持注册为默认应用。打开设置本身不会更改文件关联。

## 已实现的功能

- 图库：原生侧栏、网格和列表、文件名搜索、排序、收藏、最近打开和文件夹历史导航。
- 缩略图：128、192、272、384 和 512 pt 五档，默认 272 pt。菜单、五刻度滑杆、两端按钮、Command＋滚轮和 Control＋滚轮共用一个状态。卡片统一为横向画幅，缩略图居中裁切，详情显示完整照片。
- 看图：完整比例预览、缩放、适合窗口、实际大小、拖动、触控板捏合、向左旋转、胶片栏和左右键切图。工具栏使用紧凑图标，文件名垂直居中。
- 评分：0～9 级，0 表示未评分。支持 Control＋数字、右键评分、详情评分菜单、精确等级筛选、最低等级筛选和按高分排序。评分保存在 Luma 中。
- 检查器：分组显示尺寸、像素数、格式、位深、评分、文件大小、色彩空间、拍摄时间、相机、镜头、曝光参数和文件位置。长内容换行，字段可以选择复制，支持本地标签。
- 全屏：系统全屏窗口、玻璃操作条、收藏和共享。macOS 26 及以上使用 `NSGlassEffectView`，较旧系统使用 `NSVisualEffectView`。
- 文件：系统打开面板、拖放图片或文件夹、Finder 的“打开方式”、系统共享面板和在 Finder 中显示文件。图库、胶片栏和详情图都支持右键复制文件名、复制路径、复制文件、粘贴文件、制作副本、重命名、打开所在文件夹和移到废纸篓。重命名保留评分、收藏和标签；复制时避开已有文件。

Command＋滚轮和 Control＋滚轮仅在图库区域切换尺寸。普通滚动用于浏览。触控板累计 28 pt 有效位移后切换一档，两次切档至少间隔 160 ms；松开修饰键后的惯性事件会被消耗。切到两端时停留在当前档位。

重排时优先保持可见的选中图片及其垂直偏移。选中图片不在视口时，保持首个可见图片。滚动位置在内容边界处钳制。字体维持系统字号，图片边缘使用固定 10 pt 圆角。

## 工具栏与菜单

排序、评分、更多和共享菜单以实际点击的控件为锚点。工具栏按钮下方弹出菜单，全屏共享面板也跟随对应按钮。键盘或菜单栏调用时，使用当前可见的工具栏按钮或内容区域作为定位依据。

鼠标移入窗口顶部时，工具栏增加背景并提高图标对比度。移出后背景渐隐，展开菜单或共享面板时保持显示。背景跟随窗口深浅色外观，并响应系统的减少动态效果和减少透明度设置。背景不遮挡照片，也不拦截按钮点击或标题栏拖动。

## 文件与状态

打开文件夹时读取该目录下的图片，跳过隐藏文件和子文件夹。单独打开图片时，会载入所在目录，并选中这张图片。损坏或系统无法识别的图片会被跳过，状态栏显示跳过数量。

支持系统 ImageIO 可解码的图片，包括 JPEG、PNG、HEIC、WebP、GIF、TIFF 和 RAW。RAW 识别覆盖 DNG、ARW、NEF、CR2、CR3、RAF、RW2、ORF 等常见扩展名。原图使用系统 `CIRAWFilter` 解码，缩略图优先使用相机内嵌预览。具体相机型号和编码由当前 macOS 的 RAW 支持决定；原生解码不可用时，会尝试显示内嵌预览。GIF 当前显示首帧。旋转只影响预览。收藏、评分、标签和界面偏好保存在应用的 `UserDefaults` 中。评分、收藏和标签不会改写原图。重命名、粘贴、制作副本和移到废纸篓是实际文件操作；示例图库中的打包资源不提供修改操作。文件在应用外移动后，需要从新位置重新打开。

示例图库使用设计目录中的 12 张真实照片。设计稿中的文件名用于示例显示，尺寸、文件大小和拍摄信息均从图片读取。示例摄影来源保留在 `Sources/Luma/Resources/Demo/manifest.json`。

## 验证

运行核心测试：

```bash
swift test
```

运行完整验收，包括构建、签名检查和真实 AppKit 窗口交互：

```bash
./scripts/verify.sh
```

窗口验收会打开测试窗口并进入全屏，结果和截图保存在 `build/validation/`。测试使用独立的偏好域和剪贴板，覆盖五档尺寸、统一卡片、滚动位置、原生控件事件、快捷键分级、评分筛选、收藏持久化、真实 DNG 解码、EXIF 读取、文件复制／重命名、全屏往返、纯图片模式、偏好设置控件和文件关联设置、原生菜单位置和顶部悬停背景。文件关联测试使用模拟接口，验证选择范围、取消处理和结果回读，不修改系统默认应用。DNG 测试样本是自建的 16 位 Bayer 文件，可用 `python3 scripts/make-raw-fixture.py` 重新生成。

窗口截图需要本机允许屏幕录制。锁屏或显示器休眠时，会跳过原生全屏往返，并在结果中记录 `SKIP`。WindowServer 截图不可用时，会输出带 `.appkit.png` 后缀的 AppKit 渲染快照，供排版检查。

## 代码结构

| 路径 | 用途 |
| --- | --- |
| `Sources/LumaCore/` | 尺寸档位、滚轮累积、图库几何、文件扫描、元数据、打开偏好和默认应用关联。 |
| `Sources/Luma/` | AppKit 应用、图库、看图画布、检查器、全屏交互和原生设置窗口。 |
| `Tests/LumaCoreTests/` | 核心行为与真实图片文件测试。 |
| `Packaging/` | 应用声明和图标。 |
| `scripts/` | 构建、运行、图标生成和窗口验收入口。 |
| `design/` | 原始设计源文件、预览和素材。 |
